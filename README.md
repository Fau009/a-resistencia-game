# A Resistência

**Jogar:** https://fau009.github.io/a-resistencia-game/

Versão digital de *A Resistência* (The Resistance) para jogar **passando um único celular** de mão em mão, de 5 a 10 jogadores.

- **Modo clássico:** líder, votação secreta da equipe, missões secretas e trilha de 5 rejeições.
- **Modo simples:** só Espiões e Resistência, sem líder e sem votação. A equipe é montada pelo grupo ou sorteada.
- O placar fica sempre visível, com cronômetro de discussão e histórico público de equipes e votos.

Este repositório guarda só a versão publicada no GitHub Pages.
